# HumanDetect 架构设计文档

> macOS 本地人体关键点检测与可视化应用
> 版本:v0.1 · 作者:架构设计稿 · 更新:2026-04-22

---

## 1. 概述

### 1.1 项目目标
构建一个 **macOS 原生桌面应用**,使用 Apple Vision 框架,对用户选择的单张图片进行 **人体 + 手部 + 面部** 关键点检测,并在图片上以点 + 骨架线的方式可视化展示,支持导出标注图与 JSON。

### 1.2 非目标(明确不做)
- 不支持 iOS / iPadOS
- 不做多人检测(只取置信度最高的一个人)
- 不做实时相机 / 视频流
- 不做云端推理、不联网
- 不做动作识别 / 姿态分类(留扩展点,不做)

### 1.3 确认的关键决策
| 项 | 决策 |
|---|---|
| 平台 | macOS 13.0+ |
| 语言 | Swift 5.9+ |
| UI | SwiftUI(主) + 少量 AppKit(拖拽、NSOpenPanel 等) |
| 推理框架 | Vision.framework(系统内置,无外部模型) |
| 检测范围 | 身体 + 手 + 脸(一期全部) |
| 人数 | 单人(取最高置信度) |
| 工程形式 | Xcode 项目(`.xcodeproj`) |
| 依赖 | 纯系统框架,无第三方库 |
| Bundle ID | `com.local.HumanDetect` |
| App 名称 | `HumanDetect` |

## 3. 架构分层

采用 **MVVM + Service** 的轻量分层,State 由 SwiftUI 的 `@Observable` / `@State` / `ObservableObject` 管理。

```
┌────────────────────────────────────────────────────┐
│                    View 层 (SwiftUI)                │
│   ContentView · ImageCanvasView · InspectorView     │
│                     PoseOverlayView                 │
└───────────────┬────────────────────────────────────┘
                │ 绑定 (Binding / Observable)
┌───────────────▼────────────────────────────────────┐
│              ViewModel 层                           │
│   AppViewModel (导入/导出/检测编排/UI 状态)           │
└───────────────┬────────────────────────────────────┘
                │ 调用
┌───────────────▼────────────────────────────────────┐
│                 Service 层                          │
│  ImageLoader · PoseDetector · ImageExporter        │
│               (纯功能,无 UI 依赖)                    │
└───────────────┬────────────────────────────────────┘
                │ 使用
┌───────────────▼────────────────────────────────────┐
│                 Model 层                            │
│  DetectionResult · PersonPose · JointPoint          │
│  Skeleton(连接与颜色定义) · DisplayOptions           │
└───────────────┬────────────────────────────────────┘
                │
┌───────────────▼────────────────────────────────────┐
│          System (Vision / AppKit / CG)              │
└────────────────────────────────────────────────────┘
```

**规则**:
- View 只负责渲染与用户事件,不直接调用 Vision。
- ViewModel 编排异步任务、持有状态、暴露 `async` 方法给 View。
- Service 是纯函数式模块,易单测,不持有 UI 状态。
- Model 是值类型(`struct`),可 `Codable`,方便 JSON 导出。

### 4.2 关键模块职责

#### 4.2.1 `PoseDetector`(核心)
封装 Vision 调用,对外暴露单一 `async` 方法:
```swift
func detect(
    image: CGImage,
    orientation: CGImagePropertyOrientation,
    options: DetectionOptions
) async throws -> DetectionResult
```
内部并行执行三个 Request:
- `VNDetectHumanBodyPoseRequest` → 身体 19 点
- `VNDetectHumanHandPoseRequest`(`maximumHandCount = 2`)→ 每只手 21 点
- `VNDetectFaceLandmarksRequest` → 76 点

三个请求用 **单一** `VNImageRequestHandler` 一次性提交:
```swift
try handler.perform([bodyReq, handReq, faceReq])
```
然后从各自 `results` 挑选 **与主体身体最匹配** 的手和脸(见 4.2.2)。

#### 4.2.2 单人选择策略
- **身体**:取 `results` 中 `confidence` 最大的那个 `VNHumanBodyPoseObservation`。
- **脸**:取 `boundingBox` 与身体头部(nose/eyes 区域)IOU 或距离最近的那张。
- **手**:将检测到的手按 **腕点到身体 leftWrist / rightWrist 的距离** 分配,每只取距离最近且低于阈值的一个。
- 降级:如果没有身体结果,则脸和手独立展示(不做匹配)。

#### 4.2.3 `ImageLoader`
- 入口:`func load(url: URL) throws -> LoadedImage`
- `LoadedImage = (cgImage: CGImage, orientation: CGImagePropertyOrientation, pixelSize: CGSize)`
- 使用 `CGImageSourceCreateWithURL` + 读取 EXIF `kCGImagePropertyOrientation`,转成 `CGImagePropertyOrientation`。
- 同样支持从 `NSPasteboard` 和 `Data`(拖拽)载入。

#### 4.2.4 `ImageExporter`
- 给定 `CGImage` + `DetectionResult` + `DisplayOptions`,在 offscreen `CGContext` 上重画关键点与骨架,生成 **原分辨率** 带标注图。
- 支持 PNG / JPEG,JPEG 质量可调。
- JSON 导出:`DetectionResult` 实现 `Encodable`,标准 `JSONEncoder`(`.prettyPrinted`)。

#### 4.2.5 `AppViewModel`
```swift
@Observable
final class AppViewModel {
    var loadedImage: LoadedImage?
    var result: DetectionResult?
    var displayOptions = DisplayOptions()
    var isDetecting = false
    var errorMessage: String?

    func openImage(url: URL) async
    func pasteImage() async
    func detect() async
    func exportAnnotatedImage(to url: URL, format: ImageFormat) throws
    func exportJSON(to url: URL) throws
}
```
- 图片加载成功后 **自动触发** `detect()`。
- `displayOptions` 改变时 **不重新检测**,只刷新叠加层。

## 5. 数据模型

```swift
enum JointCategory: String, Codable {
    case body, leftHand, rightHand, face
}

struct JointPoint: Codable, Hashable {
    let name: String            // e.g. "nose", "leftWrist", "thumbTip"
    let category: JointCategory
    let normalized: CGPoint     // Vision 原始,左下为原点,[0,1]
    let confidence: Float
}

struct PersonPose: Codable {
    let bodyConfidence: Float?
    let body: [JointPoint]      // 可能为空
    let leftHand: [JointPoint]
    let rightHand: [JointPoint]
    let face: [JointPoint]
}

struct DetectionResult: Codable {
    let sourceFileName: String?
    let imagePixelSize: CGSize
    let orientationRawValue: UInt32
    let elapsedMs: Double
    let person: PersonPose?
}

struct DisplayOptions {
    var showBody = true
    var showHands = true
    var showFace = true
    var showSkeleton = true
    var showLabels = false
    var confidenceThreshold: Float = 0.3
    var pointRadius: CGFloat = 4
    var lineWidth: CGFloat = 2
}
```

**骨架连接**(`Skeleton.swift`):硬编码部位连接对,按类别分表,例如:
```swift
static let bodyEdges: [(VNHumanBodyPoseObservation.JointName,
                       VNHumanBodyPoseObservation.JointName)] = [
    (.nose, .neck), (.neck, .leftShoulder), (.neck, .rightShoulder),
    (.leftShoulder, .leftElbow), (.leftElbow, .leftWrist),
    ...
]
static let handEdges: [(VNHumanHandPoseObservation.JointName,
                        VNHumanHandPoseObservation.JointName)] = [...]
```

## 6. 关键技术要点 / 踩坑清单

### 6.1 坐标系转换(最重要)
Vision 使用 **左下原点归一化坐标**,SwiftUI / CoreGraphics 用 **左上原点像素坐标**。统一封装到 `CoordinateMapper`:
```swift
static func viewPoint(from normalized: CGPoint,
                      imagePixelSize: CGSize,
                      viewSize: CGSize,
                      fit: FitMode = .aspectFit) -> CGPoint
```
- 先:`px = (n.x * W, (1 - n.y) * H)`
- 再:按 `aspectFit` 的缩放 + letterbox 偏移映射到视图坐标。

### 6.2 EXIF 方向
**必须** 把方向同时传给:
1. `VNImageRequestHandler(cgImage:orientation:options:)`
2. 渲染图片时(SwiftUI `Image` 默认不应用 EXIF,需我们旋转或用 `NSImage`)
保证 **检测空间** 与 **显示空间** 方向一致,否则点位会偏。

### 6.3 手部关键点特殊性
- `VNDetectHumanHandPoseRequest.maximumHandCount = 2`
- 结果中每只手是一个 `VNHumanHandPoseObservation`,含 4 指 + 拇指各 4 个 + 腕 1 个 = 21 点
- 左右手区分靠 **与身体 wrist 的距离**,而不是 API 本身。

### 6.4 面部关键点
- `VNDetectFaceLandmarksRequest` 点是 **相对 faceBoundingBox** 的归一化坐标,需要先做 `boundingBox → image` 的二次映射。
- 封装在 `PoseDetector` 内部,对外统一成 `JointPoint.normalized`(相对整图)。

### 6.5 性能
- 单张图:body+hand+face 在 M1 Pro 约 80-150ms,直接 `await` 即可。
- UI 绘制:用 SwiftUI `Canvas`(不是 `ZStack + 多个 Circle`),避免一堆 `View` 对象。

### 6.6 内存
- 大图(>20MP)先按屏幕 DPR 下采样用于显示,但 **检测用原图** 保证精度。
- 导出标注图用原图尺寸重绘。

### 6.7 沙盒权限
App Sandbox 开启,`entitlements` 中:
- `com.apple.security.files.user-selected.read-write`(文件选择)
- `com.apple.security.files.bookmarks.app-scope`(可选,记住最近文件)
**不需要** 网络、相机、麦克风权限。

## 7. UI / 交互规格

### 7.1 主窗口布局
- `NavigationSplitView` 或 `HSplitView`:左(主画布) + 右(Inspector,可折叠)。
- 顶部 `.toolbar`:打开 / 粘贴 / 重新检测 / 导出图 / 导出 JSON / 适应窗口 / 折叠 Inspector。

### 7.2 画布交互
| 操作 | 触发 |
|---|---|
| 打开文件 | 菜单 File → Open / ⌘O / 拖拽到窗口 / ⌘V 粘贴 |
| 缩放 | 滚轮 + ⌘ / 触控板捏合 / ⌘+、⌘- |
| 平移 | 按住空格 + 拖拽 / 触控板双指 |
| 适应窗口 | ⌘0 |
| 1:1 | ⌘1 |

### 7.3 Inspector 面板
- 检测信息:图片尺寸、耗时、body 置信度、是否检测到手/脸
- 显示开关:身体 / 手 / 脸 / 骨架 / 标签
- 滑块:置信度阈值、点半径、线宽
- 按钮:重新检测、清除、导出

### 7.4 空状态
未导入图片时显示大的提示区域:"拖拽图片到这里,或点击打开"。

### 7.5 错误处理
- 统一通过 `AppViewModel.errorMessage` 触发 `.alert`。
- 加载失败、不支持格式、Vision 抛错、导出失败都以友好文案展示。

## 9. 并发与状态

- 所有 Vision 调用用 `async/await`,在 `Task.detached(priority: .userInitiated)` 中执行,避免阻塞主线程。
- UI 刷新回到 `@MainActor`。
- `AppViewModel` 标 `@MainActor`,Service 不绑定 actor。
- `detect()` 期间显示进度 Spinner,禁用重复触发。

## 15. 风险与对策

| 风险 | 对策 |
|---|---|
| 坐标/方向错位 | 集中到 `CoordinateMapper`,写单测 + 准备几张 EXIF 各方向测试图 |
| 手与人不匹配 | 匹配策略可配置阈值;极端情况允许单独显示手 |
| 脸部 landmark 点太多太密 | 默认点径更小,或合并为区域折线(眼眶/嘴唇) |
| SwiftUI Canvas 大量点性能 | 用 `Canvas` + `GraphicsContext.stroke/fill`,避免 ForEach 套 Circle |
| macOS 13 API 可用性 | 每个 API 用前查文档;必要时 `if #available` 降级 |
