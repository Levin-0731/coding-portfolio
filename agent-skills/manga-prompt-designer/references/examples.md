## 视频生成示例

```
【镜头设置】固定机位，无移动，无变焦，无镜头抖动，画面完全静止。中景构图，桌面及上半身始终在画面内。
【背景变化】背景完全静止不动，书架、软木板、绿植、环形灯等所有环境元素保持不变。
【人物动作（按时间顺序）】
1. 起始（0s~1s）：人物面朝镜头，双眼直视镜头，右手端咖啡杯，左手自然摊开，面带微笑。
2. 嘟嘴向左（1s~2.5s）：头部微微转向画面左侧（约15°），嘴唇嘟起做出俏皮飞吻表情，眼神始终保持看向镜头，左手轻微上扬配合动作。
3. 嘟嘴向右（2.5s~4s）：头部平滑转向画面右侧（约15°），保持嘟嘴表情，眼神不离开镜头，动作节奏与向左时对称。
4. 定格 Pose（4s~5s）：头部回正面朝镜头，嘴唇从嘟嘴过渡为自信微笑，左手摊开做展示姿势，右手端杯微抬，定格呈现"OOTD 时尚博主"经典 Pose，保持 1 秒不动。
【全程约束】人物双眼始终注视镜头方向，身体不离开座位，手中咖啡杯不消失，动作幅度柔和自然，保持卡通插画风格的一致性，人物不要张嘴说话
```
