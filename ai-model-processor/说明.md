我想要开发一个本地脚本，脚本最核心的作用是“调用 API 进行批处理”

读取一份 Excel 或者 csv，调用一个 API，用一份 prompt进行批量处理，输入输出可能是文本、图片、视频其中的一种；

批处理时需要记录日志，需要有进度条和耗时的预测

需要有一份 YAML 配置文件，配置API 供应商、模型、任务类型、输入输出、prompt 等；
API 及供应商应该是都列出来，然后 YAMl 里指定一个？

我是 PM，我期望的原则是：
- 通用性 — 一套脚本覆盖所有任务类型与运营商；新增能力是"长进框架"，而不是在旁边孤立地再写一个脚本。
- 可配置性 — 切换 模型、输入输出、任务类型、prompt 等，全部通过 YAML 配置完成，不改代码。
- 可测试性
