# 本地裁剪工具

双击「启动.command」，浏览器将自动打开网页。终端窗口需保持打开，按 Control+C 停止。

- 选择或拖入图片、视频，在框外拖动框选裁剪区域；拖动四边和四角手柄微调，拖动框内移动整个选区。固定比例下微调会保持比例。
- 支持自由比例、常用比例与精确像素输入；像素输入会切换到自由比例。
- 视频可预览并输入起止秒数，导出 MP4，保留音频。为适配 H.264，奇数画幅会缩小到相邻偶数尺寸。
- 图片可导出 PNG、JPG、WebP；JPG 透明区域填白。
- 素材留在本机；视频输出临时保留至服务退出，下载后自行保存。

依赖 Python 3 与 FFmpeg，本机已检测安装。无需网络或在线账号。
若 macOS 阻止双击启动，可在终端执行：python3 server.py（先进入本目录）。
浏览器能否预览 HEIC、MOV 等取决于浏览器和源编码；推荐 Safari 或 Chrome，优先使用 PNG、JPG、MP4。

导出时显示本机提交进度、FFmpeg 实际编码百分比，封装完成后显示 100% 与下载链接。图片编码期间显示处理中。

自动缓存最近一次导入的文件、裁剪范围及截取时间，刷新或重启后在同一浏览器自动恢复。默认固定地址 http://127.0.0.1:57645。缓存保存在当前浏览器，清除网站数据后会丢失；浏览器存储空间不足时会提示，仍可继续导出。
