# 羽毛球计分

场边用的羽毛球计分器。打开 `index.html` 即可，不需要安装依赖，断网也能记。比分存在本机浏览器里。

## 规则

按羽毛球 21 分制：

- 每局先到 21 分，且必须净胜 2 分；20 平后继续，29 平后先到 30 的一方胜
- 赛制可选一局定胜负、三局两胜、五局三胜
- 单打发球区：发球方分数为偶数从右区发，奇数从左区发
- 双打：连续得分时由同一个发球员左右换区；这一分是接发方拿到的，则由对方当前对应半区的球员发球
- 打到 11 分暂停 60 秒；局间休息 120 秒并交换场地
- 决胜局（以及一局定胜负）有一方先到 11 分时交换场地

## 用法

- 点一侧加一分。电脑上也可以用左右方向键加分，Backspace 撤销
- 「交换场地」只调转屏幕左右，不改比分，方便手机换手
- 一场结束后可以复制比分。历史记录留在本机，最多 50 场
